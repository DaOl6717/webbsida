Project-Jorgen

Project-Jorgen is a restoration and development project started in 2023 together with a friend. There isn't really a set out goal, we just want to add as much tech as possible to a bike we bought second hand.

View on GitHub
Project progress 8%

The Challenge

Restoring the bike, understanding embedded systems, programming sensors, etc. There's a lot of challenges to unpack with this project, but the biggest one is probably finding the time to work on it...

Technical Details

Currently it consists of the bike, paired with an Arduino Nano, hall effect sensor and a Bluetooth connection to send velocity data to an Android phone. Compared to GPS data, the speedometer seems quite accurate.
