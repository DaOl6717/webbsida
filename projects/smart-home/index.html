Current Status

I am not really working on developing this project anymore, mostly spending time on upkeep. The main features, the dashboard, and the automations are set up as I want them to be. If I find time, I might implement a way to turn on/off the home server either upon request or through some automation. E.g automatically turn it off during the night, and starting it again during the early morning to save on my electricity bill. I would also like to get a new device to host my wall mounted dashboard, but the current (really old) iPad works good enough for now. Finally, some other upcoming projects might tie in to this ecosystem.

Technical Details

Several Matter connected sensors and lights, together with WiFi connected devices like a wall mounted iPad functioning as the dashboard. Together, they enable different automations, self hosted DNS Server to block ads, desktop work and gaming away from home, and enable other opportunities for self hosting that does not fit on the home lab.
